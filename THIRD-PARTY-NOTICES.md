# Third-party notices

tLib's release contains third-party code and assets. Their licences require
their copyright and permission notices to travel with the distribution; this
file is that notice. It does not change tLib's own licence, which is MIT and
ships as `LICENSE`.

## How this list was produced

The package list is **measured, not declared**. The declared dependency closure
is an upper bound: rolldown and bun both tree-shake, and `client/web`'s
`package.json` declares packages that reach no shipped byte. So each shipped
bundle was rebuilt with an external source map and the `sources` array read
back to the package that produced every module in it:

| Shipped file | How it was measured | Third-party packages found |
| --- | --- | --- |
| `client/ui/assets/index-*.js` | `vp build --sourcemap` | 41 |
| `client/ui/assets/hud-layout.js` | `bun build --sourcemap=external` | none |
| `server/dist/bundle.js` | `bun build --sourcemap=external` | 2 |
| `client/ui/assets/index-*.css` | read directly | `@unocss/reset` (below); the rest is generated utility CSS |
| `server/lib/http/icons.json` | read directly | the Lucide icon set (below) |

Measured 2026-10-23. Re-measure after a dependency change: a package added to
the bundle and not added here is the failure this file exists to prevent.

## Lucide icons — ISC

Two shipped artifacts carry Lucide:

- `server/lib/http/icons.json` — 1,969 entries, generated by
  `scripts/build-icons.ts` from the Lucide set in `@iconify/json`
  (`json/lucide.json`: set "Lucide", author "Lucide Contributors", declared
  licence ISC). Which release of `@iconify/json` is not recorded and is not the
  installed 2.2.532, which regenerates the file with 2,144 entries; the set and
  its licence are the same either way. The generator strips the five
  presentation attributes every icon repeats; the path geometry is Lucide's,
  unmodified.
- `client/ui/assets/index-*.js` — `lucide-solid` 1.47.0, of which 76
  icon components are in the bundle.
