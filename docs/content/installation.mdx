## Prerequisites

- A FiveM server

---

<Steps>

### Download

Download the latest release from [GitHub Releases](https://github.com/tommy141x/tLib/releases).

A source checkout is not enough on its own — the release contains the built NUI page and
server bundle. To work from source, see *Building from source* in the repository README.

### Extract

Place the `tLib` folder in your server's `resources` directory.

### Start the Resource

Add to your `server.cfg` **before** any resource that depends on it:

```txt title="server.cfg"
ensure tLib
```

</Steps>

---

## Usage in Your Resource

Declare the dependency in your resource's `fxmanifest.lua`:

```lua title="fxmanifest.lua"
dependencies { 'tLib' }
```

### Using exports

Call tLib systems directly via exports. Toasts are the shortest thing to prove the install
with:

```lua
exports['tLib']:ShowToast(nil, 'success', 'tLib is running', 'Installed correctly.')
```

The menu is registered rather than built imperatively — pages are declared on the server and
handlers on the client. See [Exports](/docs/tLib/exports) and
[Menu Consumers](/docs/tLib/menu-consumers).

### Using import modules

For lightweight Lua modules (coords, kvp, settings, layouts), declare them in your
`fxmanifest.lua` and add the imports script:

```lua title="fxmanifest.lua"
dependencies { 'tLib' }

shared_scripts {
    '@tLib/imports.lua',
}

tlib_modules {
    'kvp',
    'settings',
}
```

Then access them via the `tlib` global:

```lua
local kvp = tlib.kvp
local value = kvp.getString('my_key', 'default')
```

Modules are lazy-loaded — they only load when first accessed.
