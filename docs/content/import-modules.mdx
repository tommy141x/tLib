## Declaring modules

`tlib_modules { 'coords', 'kvp' }` still works and makes a load eager, which fails at boot
on a module that does not compile. Both spellings are accepted (`tlib_module`,
`tlib_modules`).

<Callout type="warning">
A name tLib does **not provide** raises nothing. The first `tlib.<name>` is then an export
proxy throwing `attempt to index a function value` wherever it is used. Pin
`tlib_min_version` instead.
</Callout>

| Declare | Why |
| --- | --- |
| `realtime` | **Required.** The server bundle registers the `rt*` exports only if a manifest names it. |
| `marketplace` | Required to register content types. Otherwise `registerType` returns `false` and warns; the resource starts, its types never register. |
| `menu` | Needed when loading the module **is** the wiring — it defines the globals `MenuSchema` and `MenuCatalog`, which shared files may read with no `tlib.menu` access to trigger the load. |

`occupancy` and `telemetry` are in `AUTOLOAD` and load themselves in every consumer.
`telemetry` defaults to studio-authored resources; declare it to opt in.

## access

Decides who may use your resource, on the server, the way the owner configures — ACE, job,
inventory item or their own function, all one shape.

```lua title="config.lua"
Config.access = {
    mode = "item",          -- everyone | ace | job | item | custom; a list passes if EITHER does
    ace  = "tdetector.use",
    job  = { police = 0, sheriff = 2 },   -- job = MINIMUM grade
    item = "radar_detector",
    count = 1,                            -- how many of `item`; default 1
    custom = function(src) return false end,
}
```

```lua
local gate = tlib.access.gate(Config.access, { key = 'detector', label = 'the detector' })

RegisterNetEvent('tDetector:deploy', function()
    if not gate:allowed(source) then return end
end)
```

| Server function | Description |
| --- | --- |
| `gate:allowed(src)` | The decision. Call it before **every** privileged action. |
| `gate:push(src)` | Recompute and send the answer to that player's client mirror. |
| `gate:invalidate(src)` | Drop the cached answer after changing what the gate reads. `nil` = all. |
| `gate:describe()` / `gate:report()` | One line of prose for `<resource>_diag`; the same, structured. Assert on `report`. |
| `access.jobs(src)` | `{ [job] = grade }` from the detected framework. |
| `access.count(src, item)` | How many of an item, from the detected inventory. |
| `access.framework()` / `access.inventory()` | The **name** detected, or `nil` — not the adapter. |
| `access.use(fw, inv)` | Pin detection. `'none'`, or `'auto'` to resume detecting. |
| `access.registerFramework(a)` / `registerInventory(a)` | Teach it about a fork. |
| `access.problems(block, label, env)` | Check a block without building a gate. |

The client half draws UI only:

```lua
local gate = tlib.access.gate({ key = 'detector' })   -- same key as the server

if gate:allowed() then showButton() end
gate:onChange(function(allowed) toggleButton(allowed) end)
gate:refresh()   -- after going on duty, picking the item up
```

<Callout type="warning">
`gate:allowed()` on the client is a cached server decision in a process the player controls.
If your net event handler does not call the **server** gate's `allowed(source)`, you have
written a suggestion, not a gate.
</Callout>

- **It fails closed, always.** An absent, unstarted or throwing framework denies; a `custom`
  that errors or returns a truthy non-boolean denies; an unset ACE denies; a gate with
  config errors denies everyone and says why.
- `problems(block, label, env)` with `env = false` catches file mistakes, which disable the
  gate. `env = true` catches `mode = 'job'` with no framework — **never check that at
  startup**, because an unstarted framework is indistinguishable from a missing one and the
  gate starts passing by itself when it appears.
- `registerFramework` takes `{ name, detect, jobs }` and must be called from a
  `server_script`, not the shared `config.lua`. `jobs` returns a **map** of job → grade, so
  a player who is both police and sheriff is expressible. Under escrow, keep one server file
  in `escrow_ignore` for it.

| Axis | Supported, in detection order |
| --- | --- |
| Framework (`job`) | `qbx_core`, `qb-core`, `ND_Core`, `es_extended`, `ox_core`, `nat2k15framework` |
| Inventory (`item`) | `ox_inventory`, `qs-inventory`, `codem-inventory`, `origen_inventory`, `core_inventory`, `tgiann-inventory`, `qb-inventory`, `ps-inventory`, `jpr-inventory` |

- The axes are independent, so nat2k15 for jobs beside ox_inventory for items works, as does
  an item gate with no framework.
- Detection needs the resource **started**, not present, and reruns whenever any resource
  starts.
- Grades are normalised across qb, ESX and ND. A framework with no grade concept reports
  `0`, so `job = { LSPD = 3 }` **denies** rather than ignoring the `3`.
- **vRP** has no adapter. Load a script with `vRP.loadScript`, call `registerFramework`,
  and report grade `0`.

## config

Validates an owner-edited `config.lua` once at startup and refuses to run on a broken one.

| Function | Description |
| --- | --- |
| `config.check(tbl, spec)` | Validates, prints every problem, returns `false` if any were fatal. |
| `config.validate(tbl, spec)` | Same checks, returns `{ ok, errors, warnings }`, prints nothing. |

```lua
local ok = tlib.config.check(Config, {
    file = 'shared/config.lua',
    keys = {
        detectionRangeMeters = { type = 'number', default = 500.0, min = 1, max = 2000 },
        speedUnit            = { type = 'string', default = 'kmh', oneOf = { 'kmh', 'mph' } },
    },
})
if not ok then return end
```

| Spec field | Description |
| --- | --- |
| `file` | Path shown in messages. Use the path the owner edits. |
| `keys` | Map of key name → definition. |
| `prefix` | Table name in messages. Default `Config`. |
| `allowUnknown` | Skip unknown-key warnings. Only for a table that legitimately holds extras. |

A key definition takes `type` (`number`, `string`, `boolean`, `list`, `table`), `default`,
`required`, `min`, `max`, `oneOf`, and `fix` to override the suggested remedy.

- **Every** problem is reported at once, each naming file, key, expected, found and a fix.
- A default fills a key the owner **omitted**; a value the owner set is reported and left
  alone, never silently replaced.
- An unknown key warns with the key probably meant, including unit-less near-misses.
- A missing `required` key is fatal.

## demo

Reports whether the server runs in demo mode — the `tlib_demo` convar, see
[Convars](/docs/tLib/convars#demo-mode).

| Function | Side | Description |
| --- | --- | --- |
| `demo.active()` | both | `true` while demo mode is on. Cheap enough for a hot path. |
| `demo.dropWrite(what)` | server | `true` when the caller must skip a write. Prints one notice per target. |

A resource on the normal primitives needs **nothing**. Your own writer that bypasses
`tlib.fs` needs one line:

```lua
local function saveData(json)
    if tlib.demo.dropWrite('data.json') then return true end
    return tlib.fs.writeResourceFile('data.json', json)
end
```

<Callout type="warning">
Return **success**, not a failure — callers treat a failed save as data loss and say so to
the player. This works only if you keep a complete in-memory mirror and treat the file as
write-behind.
</Callout>

Never let `demo.active()` decide something a player benefits from being wrong about on the
client. The client value is pushed by tLib, so it is correct whether the owner wrote `set`
or `setr`.

## devgate

A gate for a feature that exists on your own servers and is **absent** from the shipped
build. `tlib.devgate(name)` returns a predicate for the convar `name`, read on every call,
on both sides.

```lua title="client/cl_feature.lua"
local isInternal = tlib.devgate('my_resource_convar')

if isInternal() then
    RegisterCommand('my_internal_tool', runTool, false)
end
```

- Put the call in a script **not** in `escrow_ignore`, or there is a convar name a customer
  can read.
- **Gate registration, not behaviour.** No command, keybind, menu row, panel or export
  should exist at all — one that exists and refuses advertises the feature in `cmdlist`.
- Read per call, so a replicated convar flipped mid-session applies at once. Where
  registration happens at load, off → on needs a restart.
- **A client VM only sees `setr`.** A client gate on a `set` convar is permanently off.
- `1`, `true`, `yes`, `on` enable it; anything else, including unset, is off.

## diag

Console blocks for the things an operator must go and fix. You write the prose; `diag` does
the wrapping, dashed rules, `^colour` codes and the `[resource]` prefix.

| Function | Description |
| --- | --- |
| `Diag.fatal(title, opts)` | Red, prefixed `FATAL:`. Nothing works until this is fixed. |
| `Diag.error(title, opts)` | Red. Something is denied or broken; the resource still runs. |
| `Diag.warn(title, opts)` | Yellow. Works, but not as intended. |
| `Diag.info(title, opts)` | White. |
| `Diag.render(level, title, o)` | The lines, without printing — for a support dump or a panel. |
| `Diag.wrap(text, width, ind)` | The word wrap on its own. |
| `Diag.said(key)` / `Diag.reset()` | Has this `once` key printed? Forget every `once` key. |

```lua
tlib.diag.fatal('Config does not exist. tRadio cannot start.', {
    cause = 'config/config.lua failed to load. Almost always a Lua syntax error.',
    fix   = 'Scroll UP: FiveM printed the exact file and line just before this message.',
    once  = 'no-config',
})
```

`opts` is `{ cause, fix, detail, scope, once }`, all optional. A `fix` list renders as "Fix
it one of these ways". It prints and never logs.

<Callout type="info">
Put these blocks in files customers receive on every update, not in `escrow_ignore`'d config
files. The partial upload that breaks a config file takes the explanation with it.
</Callout>

## modules

Server-side content discovery. A **module** is a folder plus a `module.json` declaring what
it is, as in `layouts/QRX-720/module.json`.

| Function | Description |
| --- | --- |
| `modules.scan(basePath, kind, resourceName?)` | The ids of every usable module of `kind`, sorted. |
| `modules.list(basePath, kind, resourceName?)` | The same as `{ id, manifest }`. |
| `modules.read(basePath, id, kind?, resourceName?)` | One validated manifest, or `nil, err`. |
| `modules.load(basePath, id, fileName, resourceName?)` | Read a file out of a module folder. |
| `modules.hasFile(basePath, id, fileName, resourceName?)` | Whether a module ships an optional asset. |
| `modules.validate(raw, id, kind?)` | Validate a decoded manifest directly. |
| `modules.clearCache()` | Clear the scan cache, for modules added at runtime. |
| `modules.onRefusal(basePath, id, err)` | Replace with your logger; called for every folder refused. |

<Callout type="warning" title="This module discovers layout and theme, never sound">
Scanning for sounds **throws**, and a `sound` manifest reaching a resource's `layouts/` is
refused by name. On a resource a sound is a flat audio file with no manifest; only the
marketplace carries one.
</Callout>

`schema`, `kind`, `id`, `name`, `version` are required; `author`, `license`, `description`,
`slug` optional. A marketplace `sound` module adds `sound.file` and may add
`sound.durationSeconds`, `sound.toneKeys`, `sound.peaks`.

- **`id` must equal the folder name, byte for byte**, which catches a rename on copy.
- **`kind` is declared, never inferred from location.** A mismatch is refused at start rather
  than 404ing on `ui.html` on a player's machine.
- **`sounds` and `themes` are reserved** and cannot be module ids.
- Content comes from a live scan, so a folder dropped in at runtime is found without a
  restart — `clearCache()` makes it visible to a scan already run.

## logger

Levelled console logging with one format everywhere: `[scope][LEVEL] message`.

| Function / field | Description |
| --- | --- |
| `logger.create(scope)` | A `log(...)` function that prefixes every line. |
| `log(...)` / `log(..., level)` | Space-joined arguments, `INFO` by default. A **trailing number** is the level and is not printed. |
| `logger.DEBUG` / `INFO` / `WARN` / `ERROR` | `1` / `2` / `3` / `4`. |
| `logger.setLevel(level)` | Minimum level printed. Default `INFO`. |

<Callout type="warning">
A trailing number is consumed as the level: `log('count', 4)` logs `count` at `ERROR`. Pass
numbers you mean to print as strings, or anywhere but last.
</Callout>

## permission

Admin and permission checks matching tLib's own rules.

| Server function | Description |
| --- | --- |
| `permission.isAdmin(src)` | `true` for `tlib.admin` or `tlib.superadmin`. |
| `permission.level(src)` | `0` none, `1` admin, `2` superadmin. |
| `permission.has(src, key)` | Any key, resolved by tLib — ACE, or a registered framework resolver. |
| `permission.hasBatch(src, keys)` | A key list in one round trip. `{ [key] = boolean }`. |
| `permission.hasAll(src, keys)` | `true` only if every key is held. An empty list is `true`. |

| Client function | Description |
| --- | --- |
| `permission.isAdmin()` / `.level()` | This player, as last answered by the server. |
| `permission.onChange(fn)` | `fn(isAdmin, level)` on every change, and once immediately. |
| `permission.refresh()` | Ask the server for a fresh answer. |

- `isAdmin` is answered inside your resource, so it works while tLib is still starting.
  `has` must ask tLib and returns `false` if tLib cannot answer, since a resolver may deny
  what ACE would grant.
- Use `onChange`, not a single read of `exports['tLib']:IsAdmin()` at start — that export is
  cached when **tLib** starts, so a revoked ace leaves a panel drawing its admin section
  until the player reconnects.

<Callout type="warning">
**In demo mode `level(src)` returns `2` for everybody**, so `isAdmin(src)` is true for
everybody — see [`tlib_demo`](/docs/tLib/convars#demo-mode). `has(src, key)` is unaffected.
The client answer is a cached decision in a process the player controls, so every privileged
net event re-resolves the ace server-side.
</Callout>

## net

A net event with its guard built into the registration.

**`net.fromServer` (client).** Runs the handler only for an event that really came from the
server (`source == 65535`), not a local `TriggerEvent` from another resource or a cheat
menu. A rejection is reported once per event name, never per call.

```lua
tlib.net.fromServer('myres:serverDefaults', function(defaults)
    applyServerDefaults(defaults)
end)
```

**`net.fromClient` (server).** The source guard, a rate limit and an optional permission
gate, applied once. The handler is called as `fn(src, ...)`.

```lua
tlib.net.fromClient('myres:saveLayout', {
    allow    = function(src) return gate:allowed(src) end,
    onDenied = function(src) TriggerClientEvent('myres:denied', src) end,
}, function(src, layout)
    saveLayout(src, layout)
end)
```

| Option | Default | Description |
| --- | --- | --- |
| `rateLimit` | `1000` | Minimum ms between one player's calls. `0` disables it. |
| `allow` | *none* | `fn(src) -> boolean`. Only `true` is a grant; throwing denies. |
| `onDenied` | *none* | `fn(src)`, so you can tell the player. |

<Callout type="warning">
Without `allow`, `fromClient` is a source guard and a rate limit — **not** a permission
gate. Pass `allow`, with a `tlib.access` gate inside it rather than a second mechanism.
</Callout>

A rate-limited call is dropped **silently**, so a feature that must reopen a panel it just
closed uses `panel:reopen()` from [opengate](#opengate), not the request path.

## opengate

The "may I open my panel?" handshake: the client asks, the server decides fresh on every
open, and the answer is one of three things.

```lua
tlib.opengate.serve({
    key      = 'settings',
    allow    = function(src) return gate:allowed(src) end,
    configOk = function() return myresConfigOk() end,
    payload  = function(src) return { isAdmin = tlib.permission.isAdmin(src) } end,
})
```

| Server option | Default | Description |
| --- | --- | --- |
| `key` | `settings` | Namespaces the wire events. Must match the client's. |
| `allow` | **required** | `fn(src) -> boolean`. A missing one denies everyone and says so at boot. |
| `configOk` | *none* | `fn() -> boolean`. Omit it with no config spec to check. |
| `payload` | *none* | `fn(src) -> table`, travelling with the reply. Draw hints only. |
| `rateLimit` | `1000` | Passed through to `net.fromClient`. |

Checks run in order: rate limit, `configOk`, then `allow`. A panel open to everyone writes
`allow = function() return true end`.

```lua
local panel = tlib.opengate.panel({
    key      = 'settings',
    onOpen   = function(data) openSettingsDialog(data) end,
    onDenied = function() toast("You don't have permission to use this.") end,
    onBroken = function() toast("This server's config has errors — ask an admin.") end,
})
```

| Client member | Description |
| --- | --- |
| `panel:open()` | Ask the server. The answer arrives as one of the three callbacks. |
| `panel:reopen()` | Re-run `onOpen` with the last answer, no round trip. `false` if there was never one. |
| `onOpen` | **Required.** `fn(payload)`. |
| `onDenied` | **Required.** A denial the player is never told about reads as a bug. |
| `onBroken` | Optional, but omitting it means a broken-config reply says nothing. |

All three replies register through `net.fromServer`, so a local `TriggerEvent` can neither
open the panel nor fake a denial. `reopen()` replays a grant and cannot create one.

## platform

The FiveM native adapter, inside **your** VM.

| Server function | Description |
| --- | --- |
| `platform.getPlayers()` / `getPlayerName(src)` | The roster. `getPlayerName` is `nil` for `src <= 0` or an empty name. |
| `platform.getPlayerPed(src)` / `getPlayerCoords(src)` | `nil` rather than a throw for a disconnected source. |
| `platform.getPlayerFrontSeat(src)` | `seat, netId` — **seats `-1` and `0` only**. A rear seat reads as `nil`, like on foot. |
| `platform.getPlayerSeat(src)` | `seat, netId` across every index. |
| `platform.getPlayerVehicleNetId(src)` | Requires OneSync. |
| `platform.getNearbyPlayers(coords, radius)` | Server IDs by squared distance. `{}` if either argument is falsy. |
| `platform.resolveNetworkId(netId)` / `isNetworkIdValid(netId)` / `doesEntityExist(e)` / `getEntityCoords(e)` | Entity lookups. |
| `platform.triggerClientEvent(event, target, ...)` / `triggerEvent(event, ...)` | Event dispatch. |
| `platform.now()` / `isServer()` | `GetGameTimer()`, and the duplicity check. |

| Client group | Functions |
| --- | --- |
| This player | `getMyId`, `getMyName`, `getMyPosition`, `getMySpeed`, `getMyEntityHandle`, `getClothingItem`, `isPlayerShooting`, `getActiveWeaponId`, `cancelAnimations`, `getIgnoredWeaponIds` |
| This vehicle | `getMyVehicle`, `getMyFrontSeat`, `getMySeat`, `getFrontSeatServerIds` |
| Other entities | `getRemotePlayerPosition`, `getNetworkEntityPosition`, `isNetworkIdValid`, `isEntityValid`, `getNetworkId`, `resolveNetworkId`, `getEntityPosition`, `getCameraState` |
| Blips | `createMapMarker`, `removeMapMarker`, `isMapMarkerValid`, `moveMapMarker`, `setMarkerRotation/Icon/Color/Scale/ShortRange/Display/Opacity/Label/HeadingIndicator`, `getPlayerMapMarker` |
| NUI focus | `showCursor`, `releaseCursor`, `setInputMode`, `setKeepInputActive`, `releaseCursorSuppressPause`, `releaseCursorDeferred` |
| Keybinds | `bindKey`, `keybinds`, `keybindConflicts` |
| Voice | `voice.isAvailable`, `voice.backend`, `voice.onAvailabilityChanged`, `voice.overrideProximityRange`, `voice.clearProximityOverride`, `voice.setSubmixForServerId`, `voice.setAudioInputIntent` |
| Misc | `now`, `getGameTime`, `loadData`/`saveData`/`removeData`, `sendToEngine`, `sendToServer`, `showChatMessage`, `emitEvent`, `getResourceId`, `wrapExport` |

`getMyVehicle()` answers `nil` or
`{ handle, type, displayType, modelHash, isDriver, isEmergency, isEngineOn }`, where `type`
is `heli | plane | boat | car` and `displayType` is `Air | Boat | Vehicle`.

<Callout type="warning">
**A BOOL native returns the number `1`, not `true`.** So `native(...) == true` is always
false, and `not not v` is not the fix either, because `0` is truthy in Lua. Use the
predicates above; they test both shapes.
</Callout>

```lua
tlib.platform.bindKey({
    id      = 'toggle',
    product = 'tRadar',
    action  = 'Toggle the radar',
    default = 'F5',
    press   = function() toggle() end,
})
```

Defaults: `group` `keyboard`, `pair` `true`, `default` `''`, which appends *"(unbound)"* to
the label. The positional form `bindKey(key, cb, eventType, bindingId, label)` also works.
Each bind is reported to the [keybind registry](/docs/tLib/exports#keybind-registry).

<Callout type="warning">
**The command token IS the stored binding.** Renaming one silently discards every player's
rebind, with no error and no migration. Pass a `token` to keep a legacy name, use `id` for a
new bind, and run any `when = false` gate *before* registration — a `RegisterKeyMapping`
seen once is in that player's settings forever.
</Callout>

`MAX_SEAT_INDEX` is `16`.

## occupancy

One shared answer to who is aboard a vehicle, in which tier, and which of them may act on
it. **The controller is the driver if one is seated, otherwise the front passenger.** In
`AUTOLOAD`.

| Client function | Description |
| --- | --- |
| `occupancy.poll()` / `.state()` | A copy of `{ seat, vehicle, netId, driver, passenger, partner, isController, tier, cabinSeat, cabinVehicle, cabinNetId }`. |
| `occupancy.isController()` | May this client act on the vehicle? |
| `occupancy.isFrontSeat()` / `.isDriver()` / `.isPassenger()` / `.isRearPassenger()` / `.isAboard()` | Predicates about **this** player; no arguments. |
| `occupancy.tier()` | `driver` \| `passenger` \| `rear` \| `nil`. |
| `occupancy.myVehicle()` | `handle, netId` — `nil` unless in a **front** seat. |
| `occupancy.cabin()` | `handle, netId, seat, tier` — any seat, so `nil` only on foot. |
| `occupancy.partner()` | The other front seat's server id. |
| `occupancy.onChange(fn)` | `fn(state)`. Returns an unsubscribe function. |
| `occupancy.startReporting()` / `.startSweep(ms)` / `.stopSweep()` | Opt in to the move ping and poll loop. Sweep default `250`. |

| Server function | Description |
| --- | --- |
| `occupancy.isControllerOf(src, netId)` / `.isFrontSeat(src, netId)` / `.isAboard(src, netId)` | **Gates.** Each re-reads the host; none can be stale. |
| `occupancy.refresh(src)` / `.refreshOccupant(src)` | Re-read and repair the cache. `seat, netId[, tier]`. |
| `occupancy.seatOf(src)` / `.occupantSeatOf(src)` / `.tierOf(src)` | The cache. |
| `occupancy.frontSeats(netId)` / `.occupantsOf(netId)` / `.controllerOf(netId)` | By vehicle. Copies. |
| `occupancy.partnerOf(src)` / `.peersOf(src)` | The other front seat / everyone aboard. |
| `occupancy.onChange(fn)` / `.onCabinChange(fn)` | Front-seat edges / every-seat edges. Both return an unsubscribe. |
| `occupancy.seatTier(seat)` / `.clear(src)` / `.startSweep(ms)` / `.stopSweep()` | Helpers. Sweep default `1000`. |

<Callout type="warning">
**Gate on the predicates, read the cache for display.** The three gates re-read the host
every call; `occupantsOf` / `tierOf` / `occupantSeatOf` are a cache repaired by a
rate-limited ping and can briefly name a seat the player has left.
</Callout>

- `seat`, `vehicle`, `netId`, `partner` and `isController` are front-seat-only and `nil` for
  a rear passenger, so `state.seat ~= nil` reads as "may I operate this". A rear passenger
  appears only in `tier` and the `cabin*` fields, and only `onCabinChange` fires for them.
- `tlib:occupancy:moved` is one event name for every resource; its payload is a hint, since
  the seat is re-read from the host.
- Neither sweep runs until you start it.

## jsonstore

The single memoised writer for one resource's JSON data file, with per-owner schema seeding,
versioning and forward migration.

| Function | Description |
| --- | --- |
| `jsonstore.open(opts)` | The store. `opts.log` is **required**; `file` defaults to `data.json`, `resource` to `GetCurrentResourceName()`. Memoised per resource and file. |
| `store:read()` / `store:section(name)` | The whole document, or one section. `{}` when absent. |
| `store:write(sections)` | Merge and persist. `false` when nothing reached the disk. |
| `store:ensure(schema)` | Seed or migrate this owner's slice. Returns what it did. |
| `store:schemaState(owner)` | That result again, or `nil`. |
| `store:locked()` | Why writes are refused, or `nil`. |

```lua
local store = tlib.jsonstore.open({ log = tlib.logger.create('tDetector') })
store:write({ props = placements })
```

<Callout type="warning">
**A lock is permanent for the session and fails closed.** An unparseable file, a malformed
`__schema`, a version downgrade, a migration that throws or deletes an unnamed key, a failed
backup or a failed write all lock the store, and every later `write` returns `false`. The
reason is logged once; `store:locked()` is how you ask.
</Callout>

- **Migrations must be idempotent.** A `write` can report success without the bytes landing,
  so the next start migrates again.
- A migration dropping a top-level key not listed in `allowRemove` is refused and nothing is
  written. Write a rename as a copy plus an `allowRemove`.
- A malformed *schema* raises rather than locking.
- `__schema` is keyed by **owner**. Never stamp a version when applying defaults, or your
  migrations will skip it.

## audio3d

Positional device audio: the server decides who is near enough to hear a vehicle-mounted
device, and the client pushes one batched frame per tick into the consumer's own NUI.

```lua
local bus = tlib.audio3d.createBus({
    event  = 'tradar:worldSound',
    range  = Config.audioRange,

RegisterNetEvent('tradar:emitWorldSound', function(payload) bus:emit(source, payload) end)
```

| Server member | Description |
| --- | --- |
| `bus:emit(src, payload)` | Receivers reached. **`0` for every rejection** — on foot, throttled, malformed, nobody near. |
| `bus:sanitize(payload)` | The whitelisted fields, or `nil` if any present field is malformed. |
| `bus:receivers(netId, sender)` | `serverIds, coords`. |
| `bus:setRange(r)` / `bus:getRange()` | Metres, clamped to `MAX_RANGE` (250). |

| `bus:forget(netId)` | Drop a vehicle's throttle state. |

`createBus` asserts `event` and `range`. Defaults: `maxReceivers` 24 (1–128),
`minIntervalMs` 100 (0–10000), `maxPerSecond` 20 (1–120). The emitter is the **vehicle**, so
a sender on foot emits nothing.

| Client member | Description |
| --- | --- |
| `audio3d.createReceiver(opts)` | Asserts `event`, `send`, `range`. `prefix` defaults to `audio3d`, `keepAliveMs` to `6000`. |

<Callout type="warning">

## drivenprop

Drives an unattached, frozen prop's world matrix from its parent vehicle's, each frame. Use
it when a prop needs a non-unit scale: scale lives in the basis-vector lengths of
`SetEntityMatrix`, which `AttachEntityToEntity` does not carry.

| Function | Description |
| --- | --- |
| `drivenprop.create(opts)` | A driver. `opts.onError` defaults to a print. |
| `driver.add(prop, parent, placement)` / `.update(prop, placement)` / `.remove(prop)` | Membership. |
| `driver.tick()` | `written, skipped`. |
| `driver.write(prop)` / `.isDriven(prop)` / `.count()` / `.clear()` | The rest. |
| `drivenprop.normaliseScale(v)` / `.isUnitScale(v)` | Clamped to `[0.1, 10.0]`; anything unusable lands on `1.0`. |
| `drivenprop.transform(basis, placement)` / `.localRotation(rx, ry, rz)` / `.toWorld(basis, L)` | The pure maths. |
| `drivenprop.handedness(f, r, u)` / `.assertHandedness(...)` / `.dot` / `.cross` | Basis checks. |
| `drivenprop.hasMoved(last, basis)` | Whether a rewrite is needed. |

- `add` **detaches, freezes and disables collision**, then writes the matrix. Undo any of
  the three and it breaks: attached loses the scale, unfrozen falls through the world,
  collision-enabled bounces off the vehicle.
- `remove` and `clear` neither delete the prop nor re-attach it; re-attaching discards the
  scale.
- `transform` raises on a left-handed basis, and returns the native's
  `(forward, right, up, at)` ordering, not the `(right, forward, up)` the rest of the
  module takes.
- `create` starts a per-frame thread and an `onResourceStop` handler; importing does not.
  Share one driver per resource.

## healthcheck

Ordered HTTP GET probes against a base URL, with retries, delivering one aggregate result.
`tlib.healthcheck(opts)` and `.check(opts)` are the same call and return **nothing**.
Everything arrives at `opts.callback` as
`{ success, steps, attempts, failedStep, message, url }`, each step being
`{ name, passed, status, error }`.

- Defaults: one step (`reachable`, path `/`), `retries` 2 (three attempts), `retryDelay`
  1000, `timeout` 8000, `delay` 500. With no `expect`, a step passes on any status 200–599.
- Give it `opts.url` or `opts.waitEvent`; `waitEvent` wins and takes the URL from the event
  payload. With neither it does nothing.
- The sequence short-circuits, so `result.steps` is shorter than `opts.steps` on a failure
  and a retry restarts at step 1. A timeout is `status = 0`, not an error.
- `%port%` in a step's `errorMsg` becomes the port parsed from the URL — 443, 80, or a
  literal `?`.

## ratelimit

A per-player minimum interval on a net event, as a closure you call at the top of the
handler.

| Function | Description |
| --- | --- |
| `ratelimit.bucket(name, intervalMs)` | Returns `fn(src) -> boolean`. **`true` means refused.** |
| `ratelimit.forget(src)` | Drop one player's timestamps. `nil` drops every player. |
| `ratelimit.reset()` | Drop the buckets themselves. Tests only. |

```lua
local gate = tlib.ratelimit.bucket('requestVehicleProps', 1000)

    local src = source
    if not src or src <= 0 then return end
    if gate(src) then return end
```

<Callout type="warning">

| Function | Description |
| --- | --- |

**You almost certainly do not need to call this.** It is in `AUTOLOAD` for studio-authored
resources; declare `tlib_module { 'telemetry' }` to opt in from any other. Whether anything
is *collected* is the `tlib_telemetry` convar — see
[Convars](/docs/tLib/convars#diagnostics).
</Callout>

| Function | Description |
| --- | --- |
| `telemetry.error(err, site, kind)` | Report a fault. Returns the stack hash — **even when deduped**. |
| `telemetry.warn(code, kind, message)` | Report a warning. A `code` that slugs to empty is dropped. |
| `telemetry.timed(operation, thresholdMs, fn)` | Run `fn`, recording how long it took. Re-raises a throw. |
| `telemetry.record(operation, thresholdMs, ms)` | The same, for something you timed yourself. |
| `telemetry.consent()` | `{ enabled, source, locked }`. A cache, not the authority. |
| `telemetry.flush()` | Send the pending batch now. |
| `telemetry.scrub(text)` / `.scrubIdentifiers(text)` | Redact registered values / anything identifier-shaped. |
| `telemetry.registerScrubValue(value)` | Add a value to redact. Refuses anything under 3 characters. |
| `telemetry.createTimers(opts)` | A private `{ record, timed, reset }`. `opts.report` is required. |

While consent is off, events are dropped rather than queued, so turning diagnostics on sends
no backlog. With it on, the queue caps at 32 and discards oldest first. A fault is deduped
for 120 seconds per fingerprint.

## screentarget

Picks the **one** vehicle whose device screen this client renders — `AddReplaceTexture` is
keyed on the texture name, so there can only be one. Your own vehicle always wins,
otherwise the nearest in range, with hysteresis.

| Member | Description |
| --- | --- |
| `screentarget.create(opts)` | An arbiter. `opts.hasScreen` is required. |
| `self.update()` | `vehicle, netId, source` — or a single `nil` when nothing qualifies. |
| `self.current()` | The same, without re-deciding. |
| `self.currentDistance()` | Distance at the last `update`; `0` for your own vehicle. |
| `self.onChange(fn)` | `fn(vehicle, netId, source)`. Returns an **unsubscribe** function. |
| `self.reset()` | Forget the incumbent. |
| `self.settings()` | `{ range, switchMargin, dwellMs }`. |

Defaults: `range` 8.0 m, `switchMargin` 2.0 m (absolute metres, not a fraction), `dwellMs`
1500. `source` is `own` or `nearest`.

`onChange` fires only on a vehicle or source change, never on distance, so it is safe to
rebuild a browser inside it. Treat `update()` returning `nil` as the signal to tear that
browser down, or it paints stale pixels onto a vehicle the player has left. `dwellMs` delays
*displacement* only. Create one arbiter per **device kind**.

## runtimetxd

Calls `CREATE_RUNTIME_TXD` at most once per resource load, and mints names a `restart`
cannot collide with.

| Function | Description |
| --- | --- |
| `runtimetxd.create(prefix)` | A per-resource txd owner. |
| `txds.ensure()` | The txd handle, created on first call and cached. |
| `txds.name()` / `txds.tag()` | The dictionary name, and the per-load tag inside it. |
| `txds.textureName(stem, serial)` | `<stem>_<tag>`, or `<stem>_<tag>_<serial>`. |
| `txds.count()` | How many times the native was **called**, not how many names. |

```lua
local txds = tlib.runtimetxd.create('tdet_scr_txd')
local name = txds.textureName('tdet_screen', serial)
```

Budget one permanently pinned streaming slot per resource load: the engine frees neither a
runtime txd nor a runtime texture, so repeated restarts accumulate them. Reusing a name
across a restart instead makes `AddReplaceTexture` resolve against the previous load's
dictionary and silently do nothing.

## soundfields

Builds the Sounds tab of a settings dialog and keeps it live, remembering which keys the
open dialog drew.

| Function | Description |
| --- | --- |
| `soundfields.append(fields, opts)` | Append the dropdowns. Mutates `fields`; returns the keys drawn. |
| `soundfields.refresh(dialogId, data, patch)` | Re-push options after a server change. Returns how many it patched. |
| `soundfields.keyOf(fieldId)` / `.fieldId(key)` | Convert between a tone key and its field id. |
| `soundfields.drawn()` / `soundfields.clear()` | The remembered key list; forget it. |

<Callout type="warning">
**Call `clear()` on submit, on cancel, *and* when the viewer turns out not to be an admin** —
the last of which never ran `append` at all. Left set, `refresh` patches fields in a dialog
that is not open.
</Callout>

The remembered list is module-level, so keep one dialog open at a time per resource.
`refresh` patches what was **drawn**, not the current config, so a sound key added
server-side after the dialog opened appears only at the next open.

## propeditor and vehicleprop

The in-vehicle prop stack. `vehicleprop` owns the model registry, the placement store and
the attach/detach lifecycle; `propeditor` owns the orbit camera and the editing UI. Create
`vehicleprop` and reach the editor through `instance.editor`.

```lua
local prop = tlib.vehicleprop.create({
    prefix = 'tdet', model = 'prop_cs_police_torch', decor = 'tdet_prop',
    saveEvent = 'tdet:savePlacement', removeEvent = 'tdet:removePlacement',
})
```

| Member | Description |
| --- | --- |
| `instance.setRegistry(cfg)` / `.isRegisteredModel(n)` / `.resolveModel(n)` / `.defaultModel()` | The model registry. |
| `instance.getPlacement(veh)` / `.setPlacements(src)` / `.getAttached(veh)` / `.detach(veh)` | Placements and props. |
| `instance.reconcile()` / `.tick()` / `.reclaimOrphans()` / `.cleanupAll()` | Lifecycle, exposed so a suite can drive it without a thread. |
| `instance.editor` | The `propeditor` instance, including `editor.driver`. |
| `propeditor.create(descriptor)` | The editor on its own, without `vehicleprop`. |
| `propeditor.orbit.*` | The camera maths — `new`, `eye`, `lookFrom`, `applyDrag`, `zoom`, `command`. |
| `vehicleprop.normaliseModelName(m)` / `.buildRegistry(builtin, cfg)` | Pure helpers. |

`create` asserts `prefix`, `model`, `decor`, `saveEvent` and `removeEvent`.

<Callout type="warning">
**`create` is not a constructor you can call twice.** One call registers 13 NUI callbacks,
two render threads, a decor type, a lifecycle thread and `playerSpawned` / `onResourceStop`
handlers. Create one per resource, at load, and share `instance.editor.driver`.
</Callout>

- **Scale decides the attach mechanism.** A unit scale uses `AttachEntityToEntity`; anything
  else is driven per frame through [`drivenprop`](#drivenprop). Never test "is this
  attached" to decide whether a prop is live — ask the tracking table.
- **`CreateObject` signals failure with `0`, which Lua treats as true.** `if not prop then`
  never catches it, and the prop simply never appears.
- **The placement, attached and model tables are emptied in place, never replaced.**
- A record the editor did not change round-trips byte-identical. `receiveEvent` accepts
  server-triggered events only (`source == 65535`).

## versioncheck
